<img src="https://img.shields.io/badge/Status-In%20Progress-EC4899?style=for-the-badge" alt="Project in progress"/>

### 💡 Project Idea

The goal is to create a platform where students can practice interview questions, record their scores and track their preparation progress in one place.

**Planned features**

- 📝 Practice coding and interview questions.
- 📊 Track practice scores and learning progress.
- 🔥 Maintain a daily preparation streak.
- 👤 Store student profiles and practice history.
- 📚 Organize questions by topic.

**Technology stack**

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Backend | Java, Spring Boot |
| API | REST APIs |
| Database | MySQL |
| ORM | Hibernate |

**What I want to learn from this project:** connecting a frontend to a backend, designing REST APIs, performing database CRUD operations and building a complete application.

> This project is currently in progress. Features will be updated as they are implemented.
